# Crumbly — Recipe Manager

Crumbly — веб-приложение для хранения, просмотра и создания рецептов.<br>
Сейчас в нём можно переключаться между страницами и просматривать примеры рецептов.

## Взаимодействие компонентов и избранное

Состояние страницы рецептов реализовано с помощью Angular Signals.

- Рецепты можно добавлять в избранное и убирать из него.
- `RecipeList` хранит массив рецептов и передаёт данные в `RecipeCard` через `input()`.
- `RecipeCard` сообщает о нажатии на кнопку избранного родителю через `output()`.
- Родитель обновляет массив через `signal.update()` без изменения исходного массива и объектов.
- `FavoriteFilter` использует `model()` для двусторонней связи с фильтром «Только избранное».
- В `RecipeCard` передаётся дополнительная разметка через `ng-content`.
- Общее количество рецептов и количество избранных вычисляются через computed().
- При отсутствии рецептов отображается пустое состояние.
- Изменения количества избранных выводятся в консоль через effect().

Карточки выводятся через `@for` с отслеживанием по `id`.

Избранное на странице списка пока независимо от страницы деталей.

## Страницы приложения

- **Главная** — приветствие и обзор разделов.
- **Рецепты** — список рецептов и их количество.
- **Добавить рецепт** — заготовка формы.
- **Детали рецепта** — пример рецепта с ингредиентами и шагами приготовления.

На странице деталей можно отметить рецепт как избранный.

## Установка и запуск

Для работы необходимы Node.js и npm.

Клонируйте репозиторий и откройте папку проекта в терминале.

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте в браузере: http://localhost:4200/

## Сборка

Для создания сборки выполните:

```bash
npm run build
```
