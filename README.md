# Crumbly — Recipe Manager

Crumbly — веб-приложение для хранения,просмотра и создания рецептов.  
Сейчас в нём можно переключаться между страницами и просматривать примеры рецептов.

## Страницы приложения

- **Главная** — приветствие и обзор разделов.
- **Рецепты** — список рецептов и их количество.
- **Добавить рецепт** — заготовка формы.
- **Детали рецепта** — пример рецепта с ингредиентами и шагами приготовления.

На странице деталей можно отметить рецепт как избранный.

## Технологии

- Angular
- TypeScript
- HTML
- SCSS

## Установка и запуск

Для работы необходимы Node.js и npm.

Клонируйте репозиторий и откройте папку проекта в терминале.

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте в браузере: http://localhost:4200/

## Сборка

Для создания сборки выполните:

```bash
npm run build
```
