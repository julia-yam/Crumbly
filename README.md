# Crumbly — Recipe Manager

Crumbly — веб-приложение для хранения, просмотра и создания рецептов.

## Возможности

- Добавление рецептов с милой SVG-заглушкой для изображения.
- Удаление рецептов и переключение избранного.
- Отдельная страница избранных рецептов, синхронизированная с общим списком.
- Ограничение количества рецептов до 5.
- Окно успешного создания рецепта.

## Сервис и состояние

Состояние рецептов хранится в `RecipeService`, зарегистрированном через `providedIn: 'root'`. Внутри сервиса есть приватный signal с массивом рецептов, а наружу передаётся readonly-signal `recipes`.

Сервис выполняет три основные операции:

- добавляет рецепт после проверки названия и лимита;
- удаляет рецепт по `id`;
- добавляет рецепт в избранное или убирает из него.

Все обновления массива выполняются иммутабельно. Количество избранных рецептов считается через `computed`.

`RecipeList`, `RecipeCreate` и `FavoriteRecipes` получают сервис через `inject()`, поэтому при изменении рецепта данные синхронно обновляются во всех этих компонентах.

## InjectionToken и лимит рецептов

В `app.config.ts` создан `RECIPE_CONFIG` — `InjectionToken` для конфигурации рецептов. Через provider с `useValue` в него передаётся лимит `maxRecipes: 5`.

`RecipeService` получает эту конфигурацию через `inject(RECIPE_CONFIG)` и не добавляет рецепт, если лимит уже достигнут. Конфигурация подключается при запуске приложения через `appConfig`.

## Страницы приложения

- **Главная** — приветствие и обзор разделов.
- **Рецепты** — список рецептов и их количество.
- **Избранное** — рецепты, отмеченные сердечком.
- **Добавить рецепт** — форма создания рецепта.
- **Детали рецепта** — данные выбранного рецепта с ингредиентами и шагами приготовления.

Страница деталей получает рецепт по ID из URL. Избранное синхронизировано с общим списком через `RecipeService`. Для новых рецептов ингредиенты и шаги пока не заполняются: страница показывает соответствующие сообщения.

## Маршрутизация

Навигация работает через Angular Router с `routerLink` и подсветкой активных ссылок.

- `/` — главная.
- `/recipes` — список рецептов.
- `/recipes/favorites` — избранное.
- `/details/:id` — детали рецепта. ID реактивно передаётся в input через `withComponentInputBinding()`.
- `/create` — создание рецепта; страница загружается лениво через `loadComponent`.

Список и избранное — дочерние маршруты `RecipesLayout` с общей панелью и собственным `router-outlet`. Query-параметр `?sort=title` включает сортировку по названию в обоих списках.

Настроены перенаправления `/home` → `/` и `/favorite` → `/recipes/favorites`. Неизвестные адреса обрабатывает последний маршрут `**`, показывающий страницу 404.

Маршрут создания защищён функциональным `authGuard`: демонстрационный флаг `isAuthenticated` разрешает доступ при `true` и перенаправляет на главную при `false`. По умолчанию доступ разрешён.

Рецепты и избранное хранятся в памяти и сбрасываются при перезагрузке страницы. Сборка проверяется командой `npm run build`.

## Установка и запуск

Для работы необходимы Node.js и npm.

Клонируйте репозиторий и откройте папку проекта в терминале.

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Откройте в браузере: http://localhost:4200/

## Сборка

Для создания сборки выполните:

```bash
npm run build
```
